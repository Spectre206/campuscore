# v0.11 — Security & Performance

**Status:** Complete
**Date:** 2026-09-02

## Objective

Strengthen the application's security posture, prepare the API for a future React frontend, and optimize database query performance using measurement-driven techniques.

## Features Implemented

### Security & React Readiness

- **Token Authentication**
  Added `rest_framework.authtoken` and configured `TokenAuthentication` alongside `SessionAuthentication` in DRF defaults.
  Endpoint: `POST /api/v1/auth/token/` (obtain token for username/password).
  Allows future React frontend to authenticate by sending `Authorization: Token <key>`.

- **CORS Configuration**
  Installed `django-cors-headers` and added `CorsMiddleware` high in middleware stack.
  Allowed origins for React dev servers (`localhost:3000`, `127.0.0.1:3000`, Vite ports).
  Ensures browser-based frontend can call API without CORS errors.

- **API Throttling**
  Global throttling with `AnonRateThrottle` and `UserRateThrottle`.
  Default rates: anonymous 100/hour, authenticated 1000/hour (adjustable for production).
  Protects API from abuse.

- **Input Validation & Authorization**
  Existing serializer and permission checks remain in place. Verified no open endpoints.

- **Production Security Settings (documented for deployment)**
  Recommended to set `SECURE_SSL_REDIRECT`, `SESSION_COOKIE_SECURE`, `CSRF_COOKIE_SECURE`, `SECURE_HSTS_SECONDS` in production via environment variables. Not enabled in local dev.

### Performance Optimization

- **Query Optimization**
  Applied `select_related` to reduce N+1 queries in ViewSets:
  - `ProgramViewSet` → `select_related('department')`
  - `CourseViewSet` → `select_related('program')`
  - `SectionViewSet` → `select_related('course', 'teacher')`
  - `EnrollmentViewSet` → `select_related('section', 'student')`
  - `AttendanceSessionViewSet` → `select_related('section', 'created_by')`
  - `AttendanceRecordViewSet` → `select_related('session__section', 'enrollment__student')`
  - `AssessmentViewSet` → `select_related('section')`
  - `GradeViewSet` → `select_related('assessment', 'enrollment__student')`

- **Database Indexes**
  Added `db_index=True` to fields frequently used in filters/ordering:
  - `Enrollment.status`, `Enrollment.enrolled_at`
  - `AttendanceRecord.status`
  - `Assessment.date`
  - `Grade.marks`

- **Query Count Test**
  Added test verifying list endpoint executes only 2 queries (count + select) with `assertNumQueries`.

## Key Learning Points

- Adding token authentication to DRF and its use for React/SPA
- Configuring CORS for cross-origin requests from frontend
- Applying throttling at global level and testing throttle classes directly
- Using `select_related` to optimize foreign key lookups
- Adding database indexes on filtered/ordered fields
- Measuring query counts with `assertNumQueries`
- Distinguishing between development and production security settings
- Understanding that CSRF applies to session auth but not token auth

## API Changes

- `POST /api/v1/auth/token/` – obtain authentication token
- All API endpoints now support both session and token authentication.
- CORS allows React dev servers.
