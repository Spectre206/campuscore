# v0.18 — Real AI Integration (Groq)

**Status:** Complete
**Date:** 2026-09-03

## Objective

Replace the mock AI provider with a real provider using the Groq API, while keeping the provider-agnostic service layer and adding asynchronous processing with Celery.

## Features Implemented

- **Groq AI Provider**
  - `ai_service/providers/groq.py` uses the Groq Python SDK to call a chat model
  - Configurable model via `GROQ_MODEL` env variable (default: `groq/compound`)
  - Parses JSON from model output, handles markdown fences with regex
- **Service Layer Update**
  - Provider registry now includes `groq` and `mock`
  - Fallback to mock provider on any AI error
- **Async Processing**
  - Celery task `generate_quiz_questions_task` handles AI generation in background
  - View redirects with task ID stored in session
  - HTMX polling updates the UI when result is ready
  - Loading spinner shown until questions are generated
- **Environment Configuration**
  - `AI_PROVIDER` (mock or groq)
  - `GROQ_API_KEY`
  - `GROQ_MODEL`
- **Testing**
  - Unit tests for Groq provider (mocked SDK)
  - Task tests with eager mode and result storage
  - View tests for loading state and partial endpoint
  - Full suite: 110 tests pass

## Architecture

```text
Django View
      │
      ▼
Celery Task (ai_service.tasks)
      │
      ▼
Service Layer (generate_quiz_questions)
      │
      ├── GroqAIProvider (real)
      └── MockAIProvider (fallback)
```

## Key Learning Points

- Integrating external AI APIs with a provider-agnostic interface
- Parsing and validating AI responses (JSON extraction, markdown handling)
- Configuring providers via environment variables
- Offloading slow AI calls to Celery tasks
- Implementing HTMX polling for async result updates
- Graceful fallback to mock provider on failure
- Testing external API interactions with mocks
- Handling eager-mode Celery in tests with `CELERY_TASK_STORE_EAGER_RESULT`

## How to Use

1. Set environment variables in `.env`:

   ```env
   AI_PROVIDER=groq
   GROQ_API_KEY=your-actual-key
   GROQ_MODEL=groq/compound
   ```

2. Ensure Celery worker is running: `celery -A config worker -l info`
3. Log in as teacher/admin and go to `/ai/quiz-generator/`.
4. Enter topic and number of questions. The page will show a loading spinner, then display generated questions.
