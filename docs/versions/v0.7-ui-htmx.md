# v0.7 — UI & HTMX Refinement

**Status:** Complete
**Date:** 2026-08-31

## Objective

Enhance the user interface with a cohesive design system, reusable components, and HTMX-powered partial page updates, while keeping Django templates as the foundation.

## Features Implemented

- **Base layout** (`templates/base.html`):
  - Responsive navbar with Bootstrap 5, brand icon (mortarboard), role-aware navigation, user dropdown with logout
  - Main content container with message display (Django messages framework)
  - Footer with version info
  - Bootstrap 5 and Bootstrap Icons via CDN
  - HTMX included via CDN
- **Custom theme** (`static/css/campuscore.css`):
  - Overrides Bootstrap CSS variables with institutional navy + gold palette
  - Defines colors for primary, accent, success, info, warning, danger, backgrounds
- **Reusable template partials**:
  - `partials/department_table.html`
  - `partials/section_table.html`
  - `partials/enrollment_table.html`
  - These include table markup and pagination controls (HTMX-aware)
- **Updated existing pages** to extend `base.html`:
  - Login page with brand card, styled form
  - Admin, Teacher, Student dashboards with card-based navigation
  - Department list with search and pagination
  - Teacher section list with search and pagination
  - Student enrollment list with search and pagination
- **HTMX integrations**:
  - Department list search: debounced input triggers partial table update
  - Section list search: same pattern
  - Enrollment list search: same pattern
  - Pagination: Next/Previous links use HTMX to load new page without full reload

## Design Decisions

- **CSS Framework:** Bootstrap 5 via CDN for component richness and speed; no build step.
- **Icons:** Bootstrap Icons via CDN for consistency with Bootstrap components.
- **HTMX:** Used selectively for search and pagination where partial updates enhance UX; no separate frontend framework.
- **Color Palette:** Navy (#14324D) + Gold (#C99A2E) as primary/accent with supporting status colors; provides professional academic feel.

## Key Learning Points

- Creating a base template with Django template inheritance (`{% extends %}`, `{% block %}`)
- Using `{% load static %}` and `STATICFILES_DIRS` to serve custom CSS
- Overriding Bootstrap CSS variables to create a custom theme without additional build tools
- Using HTMX attributes: `hx-get`, `hx-target`, `hx-trigger`, `hx-push-url`
- Returning partial HTML for HTMX requests by checking `HX-Request` header in views
- Django `Paginator` and `Q` objects for search/filter
- Using `render_to_string` to generate partial template responses
- Role-aware navigation in templates using `user.role` and `user.get_role_display`
- Integrating Bootstrap components (navbar, cards, tables, badges, pagination)

## How to Run

```bash
source venv/bin/activate
python manage.py runserver
```

- Login at `/accounts/login/`
- Admin dashboard at `/accounts/`
- Teacher sections at `/my-sections/`
- Student enrollments at `/my-enrollments/`
- Departments at `/departments/`
