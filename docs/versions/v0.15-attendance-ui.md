# v0.15 — Teacher Attendance UI & Student Summary

**Status:** Complete
**Date:** 2026-09-03

## Objective

Provide a user-friendly web interface for teachers to manage attendance sessions and mark attendance, and for students to view their own attendance summary.

## Features Implemented

- **Teacher attendance section pages**
  - List attendance sessions for a section (`/sections/<section_id>/attendance/`)
  - Create new attendance session (date, optional title)
  - Mark attendance for a session using a bulk form listing all active enrollments
  - Update or create attendance records with status and remarks
- **Student attendance summary**
  - Page `/my-attendance/` shows summary per enrolled section
  - Displays total sessions, present count, and percentage with color-coded badges
- **Permissions**
  - Only teachers can manage attendance for their own sections
  - Only students can view their own summary
- **URL naming conflict resolved** by prefixing web attendance URLs with `section-`
- **Dashboard links updated**: teacher section list includes "Attendance" button; student dashboard links to attendance summary

## Key Learning Points

- Building bulk update forms using `modelformset_factory`
- Handling initial data for formset based on existing records
- Using `update_or_create` for bulk attendance record upserts
- Resolving URL name conflicts between API router and custom web views
- Creating role-specific summary pages with aggregation
- Reusing Bootstrap table and badge components for UI

## How to Test

1. Log in as a teacher.
2. Go to `My Sections` → `Attendance` for a section.
3. Create a session and mark attendance for students.
4. Log in as a student and go to `My Attendance` to see summary.
