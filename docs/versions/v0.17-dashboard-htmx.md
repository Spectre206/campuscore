# v0.17 — Dashboard Redesign & HTMX Enhancements

**Status:** Complete
**Date:** 2026-09-03

## Objective

Revamp the role-based dashboards with modern card layouts, statistics, and quick links. Improve overall navigation and base template with a wider navbar and polished footer.

## Features Implemented

- **Base template upgrade**
  - Wider container (`container-xxl`) for navbar and main content
  - Taller navbar with shadow for depth
  - Multi-column dark footer with brand description, quick links, and version info
  - Profile dropdown with user icon
  - Fixed footer to bottom using flexbox
- **Admin dashboard**
  - Stat cards for departments, programs, courses, sections, teachers, students
  - Quick actions for managing departments, users, sections, API docs
  - Recent notifications list
- **Teacher dashboard**
  - Stats: number of sections, upcoming sessions count, recent assessments count
  - Quick actions: My Sections, AI Quiz Generator
  - Upcoming sessions list with mark attendance link
- **Student dashboard**
  - Stats: enrollments count, attendance percentage, recent grades count
  - Quick actions: My Enrollments, Attendance Summary, Grade Summary
  - Recent grades list with marks/total and course code
- **URL conflict fix**
  - Renamed web department URL from `department-list` to `department-list-page` to avoid conflict with API router name.

## Key Learning Points

- Using Django aggregation functions in dashboard views to provide stats
- Building responsive card layouts with Bootstrap grid
- Handling URL name conflicts between web views and DRF routers
- Using context data to render role-specific dashboard content
- Improving base template with modern design and sticky footer

## How to Test

1. Log in as admin, teacher, and student.
2. Verify each dashboard displays correct stats and links.
3. Ensure all quick action links navigate to the intended web pages, not API endpoints.
