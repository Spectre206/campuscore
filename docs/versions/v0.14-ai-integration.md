# v0.14 — AI Integration

**Status:** Complete
**Date:** 2026-09-03

## Objective

Add a simple AI-powered feature: help teachers draft quiz questions based on a topic or course material. The AI service is behind a provider-agnostic service layer, starting with a mock provider and synchronous execution.

## Features Implemented

- **New Django app: `ai_service`**
- **AI service layer**
  - Abstract base class `AIProvider` (`ai_service/providers/base.py`)
  - `MockAIProvider` (`ai_service/providers/mock.py`) returns deterministic sample multiple-choice questions
  - Service function `generate_quiz_questions(provider_name, topic, num_questions)` selects provider and calls generation
  - Provider registry in `ai_service/service.py`
- **Teacher UI**
  - Page: `/ai/quiz-generator/`
  - Accessible only to `TEACHER` and `ADMIN` roles
  - Form with topic and number of questions (3, 5, 10)
  - On submit, calls AI service synchronously and displays generated questions
  - Error handling if provider fails
- **Permissions**
  - Custom `@role_required` decorator used
  - Students get 403 Forbidden
  - Unauthenticated users redirected to login
- **Tests**
  - Unit tests for `MockAIProvider` (format, count, determinism)
  - Service tests for provider registry and unknown provider error
  - View tests: teacher access, student forbidden, unauthenticated redirect, successful generation, invalid form
  - All 105 tests pass

## Architecture

```text
Django App (ai_service)
      │
      ▼
Service layer (service.py)
      │
      ▼
Provider interface (AIProvider)
      │
      ├── MockAIProvider (current)
      └── (Future: OpenAI, local model, etc.)
```

## Key Learning Points

- Designing a provider-agnostic service layer with abstract base classes
- Using a simple registry to select providers
- Creating role-restricted views with custom decorators
- Building forms with Django forms and rendering manually in templates
- Handling service errors gracefully in views
- Testing provider logic and view permissions
- Keeping AI output as assistance, not automatically correct; core app works without AI

## How to Use

1. Log in as a teacher or admin.
2. Go to `/ai/quiz-generator/`.
3. Enter a topic and choose number of questions.
4. Click Generate.
5. Review the mock questions.
