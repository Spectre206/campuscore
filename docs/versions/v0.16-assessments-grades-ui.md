# v0.16 — Teacher Assessments & Grades UI

**Status:** Complete
**Date:** 2026-09-03

## Objective

Provide a user-friendly web interface for teachers to manage assessments and record grades, and for students to view their own grade summary.

## Features Implemented

- **Teacher assessment pages**
  - List assessments for a section (`/sections/<section_id>/assessments/`)
  - Create new assessment (name, type, total marks, date)
  - Enter grades for an assessment using a bulk form listing all active enrollments
  - Update or create grades with marks and remarks
  - Validation ensures marks are between 0 and total marks
- **Student grade summary**
  - Page `/my-grades/` shows per-section summary with assessment count, total obtained, total possible, and percentage
  - Color-coded badges for performance (≥75% green, ≥50% warning, else danger)
- **Permissions**
  - Only teachers can manage assessments and grades for their own sections
  - Only students can view their own summary
- **Dashboard links updated**: teacher section list includes "Assessments" button; student dashboard links to grade summary

## Key Learning Points

- Building bulk update forms using `modelformset_factory` for grade entry
- Custom validation for marks range inside view (cross-field with assessment total_marks)
- Using `update_or_create` for efficient upsert of grades
- Aggregating sums for grade summary (total obtained, total possible)
- Reusing Bootstrap table and badge components for consistent UI
- Managing role-based access to assessment/grade pages

## How to Test

1. Log in as a teacher.
2. Go to `My Sections` → `Assessments` for a section.
3. Create an assessment (e.g., Midterm, total 50).
4. Click "Enter Grades" next to the assessment.
5. Enter marks for students and submit.
6. Log in as a student and go to `My Grades` to see summary.
